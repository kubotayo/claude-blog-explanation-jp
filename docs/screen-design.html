2-4. フィルター仕様

フィルター種別選択肢動作
重要度全て / S / A / B / C単一選択。選択した重要度の記事のみ表示
対象読者全て / エンジニア / ビジネス / 一般 / 研究者単一選択。targetAudience に選択値が含まれる記事を表示
フィルターは URL クエリパラメータ（?score=S&audience=engineer）に反映する。ページ再読み込み後も状態を維持でき、URLの共有が可能になる。

Anthropic が待望の Claude 4 シリーズを発表。Opus 4・Sonnet 4・Haiku 4 の3モデルが同時リリースされ、特にコーディング・数学的推論能力が前世代比で大幅に向上しています。API の一部 breaking changes が含まれるため、既存ユーザーは移行ガイドの確認が必要です。
詳細解説

モデル性能の向上

Claude 4 Opus は SWE-bench において前世代比 +15% のスコアを記録。特に複数ファイルにまたがるリファクタリングや、曖昧な仕様を推論で補う能力が顕著に改善されました。

API の変更点

thinking パラメータの仕様変更など、主要な breaking changes があります。移行ガイドを参照してください。

ポイントまとめ
エンジニア向けポイント
  • SWE-bench スコア前世代比 +15%
  • thinking パラメータの仕様変更
  • 並列 Tool Use がデフォルト有効に
  • 移行ガイドは公式ドキュメント参照
ビジネス向けポイント
  • Haiku 4 は前世代比コスト -30%
  • 企業向け API の SLA 向上
  • 日本語性能が大幅に改善
  • 既存契約への影響なし
日本での活用イメージ

日本語性能の向上により、国内の金融・医療・法律分野での文書処理自動化がより現実的になりました。特に複雑な契約書のレビューや、医療記録のサマリー生成での活用が期待されます。
